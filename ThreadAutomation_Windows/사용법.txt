🎯 Thread Automation - Windows 사용법

📁 이 폴더를 Windows 컴퓨터로 복사하세요!

🚀 가장 간단한 방법:
1. run_as_admin.bat 파일을 우클릭
2. "관리자 권한으로 실행" 선택
3. 자동으로 프로그램 실행

🔧 다른 방법:
1. run.bat 파일을 더블클릭
2. Python이 설치되어 있어야 함

⚠️ 주의사항:
- Python이 설치되어 있어야 함
- Google Chrome이 설치되어 있어야 함
- 인터넷 연결이 필요함
- 과도한 자동화는 계정 정지의 원인이 될 수 있음

💡 팁:
- 처음에는 설정을 낮게 해서 테스트해보세요
- 딜레이를 충분히 설정하여 봇 탐지를 방지하세요
- 하루 최대 100-200개 계정까지만 처리하는 것을 권장합니다

🎉 완료되면 Thread Automation 프로그램이 자동으로 실행됩니다!
