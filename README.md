# 스레드 자동화 도구

스레드(Threads)에서 특정 키워드로 검색하고 자동으로 상호작용하는 도구입니다.

## 주요 기능

- 🔍 **키워드 검색**: 여러 키워드로 동시 검색
- ❤️ **자동 좋아요**: 검색된 포스트에 자동으로 좋아요
- 🔄 **자동 리포스트**: 포스트 자동 리포스트
- 👥 **자동 팔로우**: 사용자 자동 팔로우
- 💬 **자동 댓글**: 설정된 댓글 템플릿으로 자동 댓글
- ⏱️ **딜레이 설정**: 봇 탐지 방지를 위한 랜덤 딜레이
- 📊 **실시간 로그**: 진행 상황 실시간 확인

## 설치 방법

1. **Python 설치** (3.7 이상)
2. **Chrome 브라우저 설치**
3. **의존성 설치**:
   ```bash
   pip install -r requirements.txt
   ```

## 사용 방법

1. **프로그램 실행**:
   ```bash
   python thread_automation.py
   ```

2. **스레드 로그인**:
   - Chrome에서 스레드에 로그인
   - 로그인 상태 유지

3. **설정 구성**:
   - 검색할 키워드 입력 (한 줄에 하나씩)
   - 자동화 옵션 선택 (좋아요, 리포스트, 팔로우, 댓글)
   - 딜레이 범위 설정
   - 댓글 템플릿 설정

4. **자동화 시작**:
   - "자동화 시작" 버튼 클릭
   - 실시간 로그 확인

## 문제 해결

### Chrome WebDriver 오류
- Chrome 브라우저가 최신 버전인지 확인
- `webdriver-manager` 패키지가 설치되어 있는지 확인

### 로그인 오류
- Chrome에서 스레드에 로그인되어 있는지 확인
- 쿠키와 세션이 유지되고 있는지 확인

### 요소를 찾을 수 없음
- 스레드 웹사이트의 구조가 변경되었을 수 있음
- CSS 선택자를 업데이트해야 할 수 있음
