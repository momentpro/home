# Auto Caller - 자동 다이얼링 앱

## 🎯 핵심 기능
**하루 수천 개의 전화번호를 완전 자동으로 처리하는 대량 통화 시스템**

- ✅ **CSV 파일 가져오기** - 전화번호 목록 자동 로드
- ✅ **완전 자동 다이얼링** - 사용자 개입 없이 순차 다이얼
- ✅ **스마트 통화 분류** - 응답/무응답/음성사서함 자동 구분
- ✅ **데이터 영구 저장** - 앱 재시작 시 목록 복원
- ✅ **최소 권한** - 전화 관련 권한 2개만 필요

## 🚀 사용법

### 1. 최초 설정 (한 번만)
1. 앱 실행 → **전화 권한 2개 허용**
2. (선택사항) 접근성 서비스 활성화

### 2. 전화번호 준비
CSV 파일 생성 (한 줄에 하나씩):
```
010-1234-5678
010-9876-5432
02-123-4567
```

### 3. 자동 다이얼링
1. **"연락처 목록 가져오기"** → CSV 파일 선택
2. **"자동 다이얼 시작"** → 완전 자동 실행
3. **모니터링** → 진행 상황 확인

## ⚡ 성능
- **시간당 200-240개** 번호 처리
- **하루 8시간 = 1,600-1,920개** 번호
- **완전 자동화** - 사용자 개입 불필요

## 🎛️ 자동 분류 시스템

| 상황 | 감지 시간 | 처리 |
|------|----------|------|
| **무응답** | 15초 후 | 다음 번호 |
| **음성사서함** | 8초 이내 연결 | 11초 후 다음 번호 |
| **사람 응답** | 8초 후 연결 | 정상 통화 |

## 📱 필요 권한
- **전화 걸기** (CALL_PHONE)
- **통화 상태 읽기** (READ_PHONE_STATE)

## 🔧 빌드 방법
```bash
./gradlew assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
```
