🎁 도민 혜택

  • 전 메뉴 30% 할인
  • 도민 추가 10% 할인 (총 40%)
  • 방문 시 신분증 지참 필수

📌 참여 방법 & 필수 안내사항

  1. 신청서 작성 → 선정 후 개별 연락 예정
  2. 예약 진행 → 선정된 분은 '캐치테이블' 앱을 통해 반드시 신청자 본인 명의로 예약
  3. 예약 확인 전달 → 예약 완료 후, 예약 확인 화면 캡쳐 이미지를 담당자에게 전달해야 혜택이 적용됨
  4. 인원 규정 → 예약 시 입력한 인원과 실제 방문 인원이 반드시 동일해야 함
    방문 전 사전 수정은 가능 (예: 2인 예약 후 4인 방문 시 할인 불가)
  5. 방문 시 할인 적용 → 예약 내역과 인원 확인 후 현장에서 최대 40% 할인
  6. 리뷰 작성 필수 → 캐치테이블 리뷰 작성 및 사진 3장 이상 첨부

⚠️ 유의사항

  • 제주도민만 참여 가능 (신분증 확인 必)
  • 다른 할인과 중복 적용 불가
  • 리뷰는 이벤트 홍보 목적으로 활용될 수 있음
  • 방문하지 않거나 리뷰 미작성 시 추후 참여 제한
